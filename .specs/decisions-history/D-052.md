# D-052

**Spec:** `features.md`

**Notifications now respect Shorts the same way the feed does, plus a new independent toggle for the case the feed toggle can't express.** A direct product-owner request/bug report, raised in conversation rather than through `tracker-current.md`: asking whether turning off "Show Shorts" (`showShorts`) also stops Shorts from triggering a new-video notification (D-050) — it didn't. `SyncService.refresh()`'s `newVideosByChannel` tally (D-050) was built from RSS-discovery counts *before* `confirmShorts()` ever runs, so every notification counted Shorts identically to any other new video, with no path to exclude them regardless of any setting. Two things landed together: **(1) the bug fix** — `newVideosByChannel` entries now also carry `shortsCount`, resolved from a new `SyncRepository.countShorts(videoIds)` right after `confirmShorts()` settles that cycle's verdicts (same refresh, so no extra sync pass); `main.ts`'s `maybeNotifyNewVideos` now always excludes Shorts from the notified count when `showShorts` is off, full stop. **(2) the requested feature** — a new `SettingsDto.notifyShorts` (default **true**, matching pre-fix behavior when Shorts are shown), which only takes effect *while* `showShorts` is on: Shorts are frequent enough content on some channels that a user may want them visible in the feed but silent for notifications, without needing to hide them outright. Combined rule in `maybeNotifyNewVideos`: `includeShorts = settings.showShorts && settings.notifyShorts` — a Short hidden from the feed never notifies regardless of `notifyShorts`; `notifyShorts` only decides the case where Shorts *are* shown. Settings only renders the new toggle while `showShorts` is also on (same conditional-visibility pattern as `startMinimized`/`popOutOnClose`). Checked via `npm run typecheck && npm run lint && npm test`; not run live — needs the owner's own hands-on check (does turning off "Show Shorts" silence Shorts notifications too; does the new toggle silence them while still showing them in the feed).
